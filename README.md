# Photo Gallery

Веб-приложение «Фотогалерея» на Flask. Позволяет загружать изображения
с подписью и видит их список на главной странице в виде плитки. Метаданные
(имя файла, подпись, дата загрузки) хранятся в PostgreSQL, сами файлы —
на диске, в директории, заданной переменной `UPLOAD_DIR`.

## Стек

- Python 3.12, Flask
- PostgreSQL (через psycopg2)

## Локальный запуск (без Docker)

1. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
2. Поднимите PostgreSQL любым удобным способом и создайте пустую базу
   данных (таблицу приложение создаёт автоматически при старте).
3. Задайте переменные окружения (см. `.env.example`) и запустите:
   ```
   python app.py
   ```

Приложение слушает **порт 5000**.

## Переменные окружения

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `DB_HOST` | хост PostgreSQL | `localhost` |
| `DB_PORT` | порт PostgreSQL | `5432` |
| `DB_NAME` | имя базы данных | `gallery` |
| `DB_USER` | пользователь БД | `gallery` |
| `DB_PASSWORD` | пароль БД | `gallery` |
| `UPLOAD_DIR` | директория для сохранения загруженных файлов | `/app/uploads` |
| `DB_CONNECT_RETRIES` | сколько раз пытаться подключиться к БД при старте | `10` |
| `DB_CONNECT_DELAY` | пауза между попытками подключения, сек | `2` |

## Раздача загруженных файлов

Приложение умеет само отдавать загруженные файлы по адресу
`/uploads/<имя_файла>` (роут `uploaded_file`) — это нужно, чтобы
приложение оставалось работоспособным и без reverse-прокси перед ним.

Однако при развёртывании за reverse-прокси запросы к `/uploads/` в норме
**не должны доходить до Python-процесса**: прокси должен раздавать эти
файлы напрямую из общей с приложением директории, что быстрее и не
нагружает приложение лишними запросами. Расположение файлов на диске
(`UPLOAD_DIR`) должно быть доступно и приложению, и прокси.

## Схема базы данных

Приложение само создаёт таблицу `photos` при старте (если её ещё нет).

## Проверка состояния

`GET /health` — возвращает `{"status": "ok"}`, если приложение работает
и может подключиться к базе данных, иначе `{"status": "error", ...}` с
кодом 503.
